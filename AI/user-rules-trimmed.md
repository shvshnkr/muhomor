# Рекомендуемые User Rules (вставить в Cursor Settings → Rules)

Замените текущие длинные глобальные правила этим блоком (~15 строк).  
Полные workflow commit/PR — только по явной просьбе или через `@` / skills.

---

```
- Отвечай по-русски, если пользователь пишет по-русски.
- Не создавай git commit и не push без явной просьбы пользователя.
- Минимальный diff: не менять несвязанный код.
- Следуй существующим соглашениям файла/пакета.
- После значимых правок в muhomor — дописать краткую запись в AI/workflowlog.md.
- Для commit/PR — следовать стандартному git/gh workflow только когда пользователь просит «закоммить» или «создай PR».
```

---

## Что убрали (и куда перенести)

| Было в User Rules | Куда |
|-------------------|------|
| Длинный commit HEREDOC protocol | По запросу «закоммить» или skill `create-commit` |
| PR create steps (gh) | По запросу «создай PR» |
| Prose/style guidelines | Уже в системном промпте; дублировать не нужно |
| «Run commands yourself» | Оставить одной строкой при необходимости |

## Проверка

Cursor → чат → **context ring** → смотреть долю **Rules**. После замены Rules должны занимать заметно меньше, чем Conversation.
