# Промпт: редизайн muhomor GUI (Fyne)

Использован при реализации `internal/ui/fyneapp/theme.go` и обновлении вкладок.

## Контекст

Desktop GUI на Fyne v2 для VPN/proxy-менеджера muhomor. Пользователь — не технарь на простом экране; расширенный режим — группы, маршруты, multipath. Сейчас выглядит как сырой прототип: плоский VBox, дефолтная светлая/серая тема, кнопки без иерархии.

## Цель

Современный **тёмный utility-клиент** (как Tailscale / Mullvad / Raycast): спокойный, уверенный, без «игрового» неона. Минимализм с **структурой**, не пустота.

|--------|----------|
| Фон | `#0f1419` глубокий slate |

## Простой экран

1. **Шапка**: название + короткий подзаголовок («умный выбор канала»).
2. **Карточка статуса**: цветной индикатор (круг) + крупное состояние + мелкая активность.
3. **Карточка деталей** (если подключено): профиль и прокси; probe/multipath моноширинно-ощущением через отдельный блок.
4. **Primary CTA**: одна большая кнопка «Подключить» / «Отключить» (HighImportance; отключение — Danger).
5. Вторичные действия в ряд: «Экспорт лога».
6. «Расширенный режим» — LowImportance, не конкурирует с CTA.

## Расширенный режим

- Вкладки сверху, контент в **scroll** где длинный (Настройки).
- Секции: заголовок + пояснение + separator.
- Кнопка «← Простой режим» — приглушённая.
- Конфигурация: тулбар в **две строки**, список профилей в карточке/scroll.

## Техника (Fyne)

- Кастомный `fyne.Theme` с override цветов и padding.
- `canvas.Rectangle` + `container.NewStack` для карточек.
- `widget.Button.Importance` для иерархии.
- Размеры окна: простой ~440×440, расширенный ~860×600.

## Не делать

- Светлую тему по умолчанию, градиенты, emoji-иконки, анимации.
- Перегрузку иконками (в проекте нет asset pack).
- Изменение бизнес-логики presenter/appcore — только presentation.
