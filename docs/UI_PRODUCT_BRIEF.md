# UI Product Brief — muhomor desktop

Документ для дизайна, ревью и приёмки GUI **без** обязательного знания UI-жаргона.  
Техническая архитектура: [`PHASE4_DESKTOP_UI_ARCH.md`](PHASE4_DESKTOP_UI_ARCH.md) (§7 — паритет Dahusim).

**Стек (2026-05):** Wails + React + Tailwind; Go: `internal/ui/wailsapp`, `presenter`, `appcore`.

---

## Для кого

- Пользователь, которому нужен **one-click VPN/proxy**, а не IDE настроек.
- Редко заходит в «Расширенный режим» — подписки, маршрут, порт, пул.

---

## Ощущение продукта

- **Спокойный, уверенный** интерфейс: «всё под контролем», без суеты.
- **Тёмная тема по умолчанию** — graphite + teal accent (см. `frontend/src/styles/tokens.css`).
- **Референсы настроения** (не копия): Mullvad, Tailscale desktop — минимализм, читаемый статус, одна главная кнопка.

---

## Не хотим

- «Пластиковые» кнопки и перегруженные панели.
- Layout, который **прыгает** при длинном тексте статуса или смене состояния.
- Перегруженный simple screen (всё важное — на первом экране, детали — в extended).
- «Деревянные» отступы (случайные 7px/13px) — только шкала 4/8/12/16/24.

---

## Экраны и паритет с Fyne

| Экран | Назначение | Было (Fyne) | Стало (Wails) |
|-------|------------|-------------|---------------|
| **Simple** | Подключение, статус, ping, экспорт | `simple_tab.go` | `pages/Simple.tsx` |
| **Extended** | 4 вкладки | `shell.go` extendedTabs | `pages/Extended.tsx` + tabs |
| **Tray** | Фоновая работа | `tray.go` | `wailsapp/tray.go` |

### Simple — обязательно

- Крупная кнопка **Подключить / Отключить / Отменить** (мин. высота ~44px).
- Hero: статус (точка + заголовок), activity, профиль/прокси, probe/standby/multipath/bulk (scroll при длинном тексте).
- Строка **Ping** (+ «Ping всех» при bulk pool).
- **Экспорт лога**.
- Ссылка **«Расширенный режим»**.

### Extended — вкладки

1. **Простой** — тот же Simple (embedded).
2. **Конфигурация** — группы, профили, подписки.
3. **Маршрут** — быстрые пресеты 0–3.
4. **Настройки** — proxy/VPN, порт, пул, multipath, daemon start/stop, reload.

### Tray

- Пункты: **Показать**, **Подключить**, **Остановить**, **Выход**.
- Закрытие окна (X) → **скрыть в tray**, демон и VPN **не** останавливаются.

## Правила layout

| Режим | Правило |
|-------|---------|
| Simple | Фиксированная логическая высота; кнопка connect на одном месте; текст статуса переносится, не сдвигает кнопку |
| Extended | Списки и таблицы в **ScrollArea**; вкладки сверху; «← Простой режим» всегда виден |

---

## Словарик (простыми словами)

| Термин | По-русски |
|--------|-----------|
| Typography | Размеры и жирность текста (заголовок / тело / подпись) |
| Spacing | Отступы между блоками (4→8→12→16→24 px) |
| Elevation | «Поднятость» карточки — чуть светлее фон, тонкая рамка |
| Accent | Цвет главных действий (teal) |
| Surface | Уровни фона: база → карточка → поле ввода |
| Hero | Верхний блок со статусом подключения |
| Connect CTA | Главная кнопка сценария |
| Tray | Иконка у часов, меню без открытого окна |
| Extended mode | Вкладки для продвинутых настроек |
| Parity | Поведение как в старом Dahusim/Fyne, без регрессий |

## Критерии приёмки (smoke)

- [ ] Portable kit Win: запуск `muhomor-gui.exe`, демон поднимается, Connect/Disconnect.
- [ ] SSE: статус и activity обновляются без ручного Refresh.
- [ ] Ping и Export log с simple screen.
- [ ] X → tray; из tray «Показать» возвращает окно.
- [ ] «Расширенный режим» → 4 вкладки, «← Простой режим» обратно.
- [ ] DPI 125%: кнопки и текст не обрезаны.
- [ ] Linux kit (если собран GUI): webkit2gtk установлен, tray или fallback «только окно».
