Конфигурация portable kit (редактируется в Блокноте)
====================================================

subscriptions.txt
  Список ссылок на подписки (по одной на строку).
  Строки с # в начале — комментарии.
  При первом подключении, если в базе ещё нет групп, демон импортирует
  эти ссылки. Пустой файл — встроенный набор по умолчанию.

settings.txt
  Справка по настройкам в GUI (порт, пул load-balance, multipath).
  Сами значения хранятся в data\muhomor.db — меняются в «Настройки» GUI.

После правки subscriptions.txt перезапустите демон и подключитесь заново.
